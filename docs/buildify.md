# Mo Be Freelance Writing Services App

## Requirements
- User authentication (writers and clients)
- Writers can create profiles and showcase their work
- Clients can browse writers and post writing projects
- Project bidding system
- Messaging between writers and clients
- Project management and delivery
- Payment integration
- Reviews and ratings system

## Design
- Modern, clean interface with professional branding
- Dashboard for writers showing active projects and earnings
- Dashboard for clients showing posted projects and applications
- Project detail pages with full project information
- Writer profile pages
- Messaging interface
